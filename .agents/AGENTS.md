# Workspace Agent Rules & Directives

## Backend Modifications Protocol (CRITICAL)
- **DO NOT MODIFY BACKEND CODE IN `src/` WITHOUT PRIOR PERMISSION**.
- Before making ANY change, addition, or refactoring in the backend codebase (`src/controllers/`, `src/routes/`, `src/models/`, `src/middlewares/`, `src/db/`, `src/utils/`), you MUST first explain the exact proposed changes to the user and obtain their explicit approval.
- Preserve 100% of existing developer comments, annotations, and docstrings in all backend files.
